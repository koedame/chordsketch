Edit ChordPro, see it render — in Svelte

This page is a real Svelte 5 app built on @chordsketch/svelte. Type on the left and the preview on the right re-renders through the same WebAssembly engine the ChordPro playground uses. Ctrl/Cmd + ↑/↓ in the editor steps the transposition.
