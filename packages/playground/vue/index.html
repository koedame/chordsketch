Edit ChordPro, see it render — in Vue

This page is a real Vue 3 app built on @chordsketch/vue. Type on the left and the preview on the right re-renders through the same WebAssembly engine the ChordPro playground uses. Ctrl/Cmd + ↑/↓ in the editor steps the transposition.
